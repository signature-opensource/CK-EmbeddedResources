An abstraction for resources identified by a string, whatever their actual origin.

A resource container behaves like a small file system: folders and resources addressed by a
hierarchical path. The same contract covers embedded resources in an assembly, a local file system
folder, and content generated by code, so consumers do not care where a resource comes from.

Resources and folders are located by two small structs whose default value is simply "not valid", which
removes nullability from the API. When a project is being built locally, an assembly's resources are
served from its source folder instead of its manifest, so editing a file does not require a rebuild.
