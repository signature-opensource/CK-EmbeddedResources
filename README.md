# CK-EmbeddedResources

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-EmbeddedResources.svg)](LICENSE)

Provides an abstraction for "resources" identified by a string that can exist as embedded resources in
assembly, be files on the local file system or dynamically created by code.

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.EmbeddedResources.Abstractions](CK.EmbeddedResources.Abstractions/README.md) | Automatic `Res/` and `Res[After]/` embedding, and the three types every resource owner needs. | [![nuget](https://img.shields.io/nuget/v/CK.EmbeddedResources.Abstractions.svg?label=CK.EmbeddedResources.Abstractions)](https://www.nuget.org/packages/CK.EmbeddedResources.Abstractions/) |
| [CK.EmbeddedResources](CK.EmbeddedResources/README.md) | Resource containers: a file-system-like view over assembly, disk and generated content. | [![nuget](https://img.shields.io/nuget/v/CK.EmbeddedResources.svg?label=CK.EmbeddedResources)](https://www.nuget.org/packages/CK.EmbeddedResources/) |
| [CK.EmbeddedResources.Assets](CK.EmbeddedResources.Assets/README.md) | Asset definitions and their composition across a Direct Acyclic Graph. | [![nuget](https://img.shields.io/nuget/v/CK.EmbeddedResources.Assets.svg?label=CK.EmbeddedResources.Assets)](https://www.nuget.org/packages/CK.EmbeddedResources.Assets/) |
